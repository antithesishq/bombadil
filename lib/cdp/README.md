# cdp

This is a fork and adaption of
[chromiumoxide](https://github.com/mattsse/chromiumoxide), licensed under MIT.
We've stripped out the protocol domains we don't need, Tokio, and most high
level abstractions. What's left is pretty much the code generated from PDL, and
then we've done a new take on the WebSocket machinery for requests, responses,
and events.
