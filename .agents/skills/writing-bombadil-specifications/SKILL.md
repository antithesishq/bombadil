# Writing Bombadil specifications

Run `bombadil skill show writing-specifications` and follow its version-matched guide.

Use the project's installed executable. For an npm development dependency,
run `./node_modules/.bin/bombadil skill show writing-specifications` from the project root.
If the guide command is unavailable, use `bombadil --version`, `bombadil --help`,
and subcommand help. Check installed TypeScript definitions before using an API.

To exercise the specification, run `bombadil skill show finding-bugs`.
To investigate a violation, run `bombadil skill show investigating-failures`.
